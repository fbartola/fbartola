## 🚀 Featured Data Science Projects

📍 **[Full Data Science Portfolio](https://github.com/fbartola/Bartolacci-Data-Science-Portfolio)**

### 🧠 [Supervised Machine Learning Playground](https://github.com/fbartola/Bartolacci-Data-Science-Portfolio/tree/main/MLStreamlitApp)
An interactive Streamlit web application that allows users to explore classification and regression models. Users can tweak hyperparameters for Logistic Regression and Random Forests to visualize real-time impacts on Accuracy, Precision, F1-Scores, and ROC curves.

### 🔍 [Unsupervised Machine Learning Explorer](https://github.com/fbartola/Bartolacci-Data-Science-Portfolio/tree/main/MLUnsupervisedApp)
A dynamic dashboard built to explore hidden patterns in unlabeled data. Features live model training for K-Means Clustering and Principal Component Analysis (PCA), complete with elbow plots, scatter projections, and silhouette scoring.

### 🏅 [Tidy Data Project: 2008 Olympics](https://github.com/fbartola/Bartolacci-Data-Science-Portfolio/tree/main/tidy_data_project)
A data wrangling and cleaning project applying formal "Tidy Data Principles" to messy historical Olympic records, utilizing Pandas to melt, split, and format data for analysis.

### 🐧 [Basic Streamlit App](https://github.com/fbartola/Bartolacci-Data-Science-Portfolio/tree/main/basic_streamlit_app)
A foundational interactive web application built with Streamlit to filter and explore a dataset of penguins based on species and bill depth.
